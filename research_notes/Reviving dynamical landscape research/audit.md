## Recommended synthesis

1. Lead with the supported continuity: revive differentiable equilibrium-bifurcation inference and extend it to one precisely defined new object, rather than claiming to invent landscape mapping.
2. Stage the scientific work: reproduce a small equilibrium case and paper/code objective differences; test Hopf-location sensitivities; then a phase-fixed periodic-orbit target; only then discretized PDE patterns with convergence/error controls. These are proposed gates, not experiments completed here.
3. Keep architecture reversible: native reference numerics, portable artifacts, and an explorer that can use CPU/Wasm f64 plus GPU visualization. Compare Julia-generated static views before assuming another UI language or a permanent server is necessary.
4. Separate discovery, numerical validation, mathematical certification and Lean checking in every result label. Start formal work with a small map-level theorem or a certificate whose semantic implication is explicitly proved; inspect existing libraries first.
5. Treat language/agent productivity and novelty as open empirical questions. Use matched tasks, repeated seeds and an explicit stack-level-versus-dispatch-level hypothesis. Report a Lean proof track separately from numerical coding tasks.
