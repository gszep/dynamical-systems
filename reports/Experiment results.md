# Experiment results — inverse bifurcation revival: equilibria, cycles, patterns

*Synthesis of executed local evidence, 2026-10-19 → 2026-10-21. No new numerical runs, searches or fetches were performed for this report; every number is quoted from committed artifacts. Links are relative to this repository; the program context is in the [research synthesis](Reviving%20dynamical%20landscape%20research.md) and the integrator checkpoint [EXPERIMENTS.md](../EXPERIMENTS.md).*

Three separate experiments toward extending the 2021 equilibrium inverse-bifurcation method to limit cycles and nonlinear PDE patterns have run on the pinned local runtime (Julia 1.10.11, SHA-verified, macOS x86_64; one thread per process, at most three concurrent processes; no CI exists, so all evidence is local). They are independent baselines, not an end-to-end extension of the original inference package. The outcomes are deliberately asymmetric: **cycles and the limited PDE baseline pass independent reruns**, while the **equilibrium released-gradient gate is retained as FAILED/INCONCLUSIVE** — a scientific result, not an infrastructure blocker.

## 1. Equilibria: reproduced package, unvalidated ∇measure

The original package (BifurcationInference.jl v0.1.4, upstream `534ee7c`, tree-hash verified, MIT notice preserved) reproduces as a **tiny functional run**: `deflationContinuation` found the saddle-node fold pair and `train!` completed 8 genuine iterations (loss 2.1667 → 2.1506), after one dependency pin *within* declared compat (KrylovKit 0.7.1; the drifted 0.8 breaks the load). This is not paper-scale reproduction (800-restart toggle-switch runs were out of scope). Parent reruns passed **184/184 stdlib probe tests** (31.59 s process wall; earlier round 101/101, 31.39 s) — independent mathematical probes: closed-form folds to <1e-10, adjoint velocities to <1e-9, and our own arclength-normalized measure gradient to 7.6e-10 against finite differences *including moving window-endpoint terms* (dropping them shifts the gradient by 0.29 and flips both component signs).

The released `∇measure` — never exercised by the package pipeline when |P|=|D| (the loss switches the measure term off) — was called directly in [audit v2](../results/01-equilibria/gradient-audit-v2/assessment.toml), summarized in the [validation file](../results/validation/equilibrium-audit-v2.toml): 21/21 audit-unit contract passes (3.55 s), assessment exit 1 (19.48 s), gate **INCONCLUSIVE_OR_FAILED**. The continuum gate is inconclusive for both components (reference 0.014910/0.506757; released values drift across ds 0.02→0.0025 with no plateau), and the same-discrete-object gate **fails** for component 2 at ds 0.02/0.01/0.005 (|G−FD| up to 9.7e-3 against a 5.1e-4 budget); FD of the returned adaptive sum is ds-unstable with a component-1 sign change. State counts are identical under ± perturbations, so discrete count jumps do not explain the instability; **no cause is identified**. Scope: scalar saddle-node, θ=(1,−1). The gate is **not validated** — and neither is any stronger claim: no O(ds) order and no incorrect-formula assertion is made. Archived raw sweeps, superseded historical pass flags and injection-verified failure paths (exit 1) are retained as failure receipts. (The audit was briefly interrupted by a provider usage limit and resumed by the same session on another model; completed sweeps were preserved and setup was not repeated.)

## 2. Cycles: accepted phase-fixed shooting baselines

The stdlib-only cycle experiment passed an independent parent rerun: **223/223 tests, exit 0, 10/10 smoke scenarios within declared acceptance sets** ([validation](../results/validation/accepted-cycles.toml)) — queue 0.003 s, supervisor setup 0.10 s, tests 37.74 s, smoke 31.61 s, total 69.45 s. Process times include Julia startup/JIT; partial internal timings are not the headline. Phase-fixed shooting treats period as an unknown and removes the neutral phase ambiguity in these nondegenerate examples. Its period-sensitivity column differentiates the **fixed-step-count discrete map**, rather than substituting the continuous-flow identity. Stuart–Landau errors are 1.5e-8 in period, 1.1e-9 in radius and 1.8e-10 in the radial multiplier. Rotational equivariance explains an exact unit phase multiplier for an exact discrete periodic solution; observed roundoff-level deviations are not an RK4 convergence signal. Van der Pol is checked structurally, including approximately fourth-order flow-invariance residual convergence. Parameter recovery errors are 8.4e-11 on the same mesh and 3.9e-9 across meshes; implicit gradients match FD to 2.7e-10. An inconsistent observable triple is flagged (residual 0.139); two observables can fit the wrong model family, while adding a multiplier exposes the mismatch (0.622). Expected negatives are checked explicitly. Scope: two 2D model families, not general cycle inference; "no cycle found" is a local search outcome.

## 3. Patterns: nonlinear branch evidence, no localized states

The final 1D subcritical Swift–Hohenberg baseline passed **224/224 tests** and explicit smoke acceptance in the independent parent rerun ([validation](../results/validation/accepted-patterns.toml)): 17.59 s tests and 13.21 s smoke process wall. These observed validation times are not comparative benchmarks. Acceptance requires positive discoveries in each sweep, usable continuation with a fold, and converged required N=32/64/128 mesh solves. Measured: **fold at r = −0.2250098** (Galerkin −0.225); **two coexisting periodic states at each** r ∈ {−0.1, −0.2}; mesh errors 1.84e-3 → 1.80e-8; and a resolution-dependent phase defect 0.543 → 6.24e-4 → 1.80e-9, replacing the false exact-null assertion for undealiased collocation. There are 41 recorded failed discovery attempts and **no new localized states** under the fixed 26-seed table—absence from this search, not nonexistence. The optional N=256 diagnostic stalled; its iterate is residual-qualified only, and the cause remains unconfirmed. Its relaxed measurement criterion does not apply to required meshes. Restriction to reflection-symmetric states is not a translation quotient and excludes asymmetric solutions; no full-space stability or exhaustive-atlas claim follows.

## Core insight

Two implementation lessons connect the experiments. First, neutral directions need explicit treatment: the transverse section (cycles) and the reflection restriction (PDE — **not** a translation quotient, excluding asymmetric states) remove a source of singularity, but do not guarantee invertibility at every bifurcation. Pseudo-arclength continuation supplies an augmented system for the tested simple fold. What is differentiated must also be specified precisely: a finite-step/adaptive-sum gradient is not automatically the continuum derivative. Second, these experiments target **nonlinear branch data beyond linear onset**: curved branches, moving window endpoints and coexistence matter, and morphology descriptors do not uniquely determine branch topology.

## Not established

No general cycle or PDE inference, no complete branch atlas, no 2D spots/stripes, no snaking, no CUDA, no Lean proof, no browser benchmark and no language comparison — none were attempted, and passing standalone suites do not imply any of them; a green stdlib suite is **not** the released-gradient gate.
